# My Travel & Mountains Portfolio

A personal portfolio website built with plain HTML, CSS and JavaScript for my class assignment.

**Live site:** https://YOUR_USERNAME.github.io/

## About the design
- Theme: travelling and mountains. A layered mountain scene with snow caps that moves as you scroll, ridge-shaped dividers between sections and an altitude meter that climbs as you scroll down.
- Interactive touches: plant flags on the peaks, dawn/night mode, snowfall, "pick my next summit", flip-over project cards and skill bars that fill as they appear.
